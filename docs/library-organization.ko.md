# 개인 라이브러리 정리

KMS Graph의 자료 원본은 Notion 또는 Google Sheets에서 관리하며, 사이트는 이를 읽어 탐색합니다. `내 정리`는 원본 자료를 수정하지 않고 이 브라우저에서만 폴더·프로젝트·자료 소속과 수동 순서를 정리하는 기능입니다.

```text
내 정리
  경영지원                  폴더
    근태 개선               프로젝트
    출장비 자동화           프로젝트
      출장 규정             자료
      출장 신청 매뉴얼      자료
```

## 구조와 범위

- 폴더 아래에 여러 프로젝트를 둘 수 있습니다. 초기 구조는 `폴더 → 프로젝트 → 자료`의 3단계이며 하위 폴더는 만들지 않습니다.
- 자료는 여러 프로젝트에서 재사용할 수 있습니다. 프로젝트에서 자료를 빼도 원본 자료와 기존 지식 그래프 관계는 삭제되지 않습니다.
- 폴더를 삭제하면 그 안의 프로젝트는 `미분류 프로젝트`로 이동합니다. 프로젝트를 삭제하면 자료의 프로젝트 소속만 해제합니다.
- 이 정리는 개인 브라우저 저장소에만 보관됩니다. 다른 기기·브라우저에는 자동으로 공유되지 않으며, Cloudflare에 게시되는 원본 자료도 바뀌지 않습니다.

## 만들기와 이동

`내 정리`의 추가 메뉴에서 폴더 또는 프로젝트를 만듭니다. 프로젝트를 선택하면 해당 프로젝트의 자료 목록과 경로가 표시됩니다.

- 폴더·프로젝트·자료의 드래그 손잡이를 잡아 이동합니다. 대상 행이 강조되면 놓습니다.
- 프로젝트를 폴더에 놓으면 폴더 소속을 바꿉니다. 자료를 프로젝트에 놓으면 현재 프로젝트에서 옮깁니다.
- 전체 자료에서 자료를 프로젝트에 놓으면 원본을 옮기지 않고 프로젝트에 연결합니다.
- 같은 단계의 행 사이 표시선에 놓으면 수동 순서를 바꿉니다.
- 검색·필터 중에는 순서 변경을 막고, 프로젝트 간 자료 이동은 계속 사용할 수 있습니다.

드래그가 어려운 환경에서는 각 행의 `더보기 → 이동하기` 또는 `위로/아래로`를 사용합니다. 모바일에서는 이 메뉴가 기본 이동 방식입니다. 이동 뒤에는 결과 알림의 `실행 취소`로 직전 한 번을 되돌릴 수 있습니다.

## 여러 자료와 안전한 정리

프로젝트 목록에서 체크박스로 여러 자료를 선택한 뒤 `이동하기`를 선택합니다. 이미 대상 프로젝트에 있는 자료는 중복으로 추가되지 않습니다. 자료를 폴더에 직접 놓는 동작과 잘못된 드롭은 변경하지 않고 이유를 알립니다. `Esc`는 진행 중인 드래그를 취소합니다.

## 내보내기와 가져오기

`내 정리` 메뉴의 `내보내기`는 개인 정리만 JSON 파일로 저장합니다. 원본 자료 내용, URL, 프롬프트, 그래프 관계는 포함하지 않습니다. 다른 브라우저에서 `가져오기`를 실행하면 형식, 라이브러리 식별자, 중복 소속을 검사한 뒤에만 적용합니다.

가져오기나 브라우저 저장에 실패하면 화면은 성공으로 표시하지 않습니다. 먼저 내보낸 백업을 보관한 뒤 브라우저 데이터를 지우는 것을 권장합니다.

## 그래프와 원본 갱신

프로젝트의 그래프는 그 프로젝트 자료와 기존 지식 관계만 보여 줍니다. 범위 밖 연결은 개수만 안내하며 전체 그래프로 이동해 확인할 수 있습니다. 원본 빌드에서 자료가 사라지면 개인 정리는 해당 자료 소속을 보류 상태로 두고, 같은 자료 ID가 다시 들어오면 복구합니다.

공용 폴더·프로젝트 구조는 아직 제공하지 않습니다. 모두에게 공유되는 정리는 Notion 또는 Google Sheets 원본에서 관리하고 정적 사이트를 다시 빌드하는 방식으로 운영해야 합니다.
