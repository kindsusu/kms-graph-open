# UI UX Pro Max 적용 기록

2026-09-08. 사용자 지정 저장소 `nextlevelbuilder/ui-ux-pro-max-skill`의 `.claude/skills/ui-ux-pro-max`를 개인 Codex skills에 설치했다. 설치된 SKILL.md, quick-reference.md의 접근성·조작·성능 항목, pro-rules.md의 적용 범위를 확인했다.

## 조회와 채택

- `knowledge management internal dashboard --design-system --density 8`: Flat Design은 참고했으나, 마케팅용 Hero/CTA 및 장식적인 서체 조합은 사내 한국어 자료 목록에 맞지 않아 채택하지 않았다.
- 좁힌 조회 `enterprise data dashboard --design-system --density 8`: Data-Dense Dashboard의 정렬된 데이터 행, 공간 효율, 필터, 행 강조를 채택했다. 함께 반환된 영업 랜딩 페이지 구조는 적용하지 않았다.
- `list sorting accessibility --stack react`: 안정적인 ID 기반 key, 의미에 맞는 HTML button/nav 지침을 확인했다.

## 페이지 적용 원칙

목록을 기본으로 제공하고, 모든 자료와 연결 그래프의 탐색을 구분한다. 자료명·유형·분야·담당자·연결 수·업데이트를 같은 열에 배치한다. 정렬은 실제 데이터에 적용한다. 아이콘은 일관된 SVG, 텍스트와 색은 의미별 토큰을 사용한다.

한국어 자료를 빠르게 훑는 사용 맥락과 작은 UI를 원한 사용자 요청을 우선해 목록 본문은 13~14px를 기준으로 한다. 웹과 네이티브 터치 기준은 구분하며 모바일에서는 넉넉한 조작 영역을 확보한다. 대비, 키보드 포커스, 축소된 모션, 작은 화면의 가로 넘침을 검수한다.

스킬 추천을 그대로 복제하지 않고 기존 그래프와 회사 지식관리 목적에 맞는 항목만 적용했다. 그래프 노드 크기 변경은 별도 `node-size-review.ko.md`의 검토안으로 남긴다.

## 검수 결과

- TypeScript/Vite 빌드 및 기존 프런트엔드 테스트 15개 통과.
- Chrome에서 기본 목록, 날짜/연결 수 정렬, 검색, 목록 내 상세 열기, 그래프 전환, 프로덕션 샘플 기본 목록을 확인했다.
- 375/768/1024/1440px 화면 폭과 reduced-motion 환경을 확인했다. 작은 화면의 하단 메뉴 잘림과 유형 텍스트 대비를 수정했다.
- 패널 배경 대비 유형/보조 텍스트 토큰의 계산값: 밝은 테마 4.58~5.59:1, 어두운 테마 6.44~8.77:1. 이는 해당 텍스트 토큰 검증이며 전체 접근성 인증을 의미하지 않는다.


## 2026-10-14 탐색 개선

기존 목록 기본 진입·개인 정리와 작은 노드를 유지했다. 현재 설치된 UI/UX 스킬을 읽고 주 에이전트가 확인한 Network Graph 권고(500개 초과 시 상세 수준 조절, 연결 목록 대체 탐색)를 적용했다. React 스킬의 stable key, 파생 상태 memo, 이벤트 해제, 키보드와 포커스 항목도 검토했다.

- 지도는 현재 검색·자료 유형·업무 분야·공용 소속 범위에서 기본 300개를 표시한다. 표시/범위 개수와 미표시 개수를 안내하고 300개씩 추가 표시한다. 배치와 노드 크기는 전체 자료의 관계를 유지하며 필터 변경으로 배치 Worker를 다시 시작하지 않는다.
- 관계 유형 필터, 선택 주변 1/2단계, 확대·축소·범위 맞춤, 목록 대체 탐색을 제공한다. 라벨은 배율과 선택 상태에 따라 제한하고, 자료 유형 텍스트·방향 설명·범례로 색상 외 의미를 제공한다.
- 다중 검색어는 모든 단어가 일치해야 하며 제목, 담당/부서/분야/태그/관계·공용 소속, 본문 순으로 점수를 준다. 빈 검색은 기존 정렬을 유지한다.
- 공용 소속은 읽기 전용 필터와 상세에 표시한다. 개인 정리 이동·연결·수동 순서 기능과 공용 원본 구조를 분리한다.
- 상세에서 출처 ID/URL, 원본 수정일, 수집일, URL 확인 상태와 관계 방향·근거를 표시한다. 재검토 후보는 명시적 의존 관계에 따른 검토 안내이며 유효성 판정이 아니다.
- 모바일 지도 조작은 44px 최소 높이, canvas 키보드 포커스 표시, 목록 탐색 대체 버튼을 제공한다. 기존 밝은/어두운 테마 토큰과 reduced-motion 배치 이동을 사용한다.

프런트 회귀 테스트에 다중 검색 순위, 1,000개 범위의 선택 보존/표시 제한, 공용 소속·출처·근거·재검토 계약 검증을 추가했다. 실제 브라우저 검수는 주 에이전트가 통합 후 수행한다.

로컬 최종 확인: `npm run typecheck`, Vitest 8개 파일/45개 테스트, `npm run build` 통과. 개발 데모에도 공용 폴더/프로젝트 계층, 출처, 관계 근거, 지난 빌드 대비 재검토 후보를 추가하여 브라우저에서 확인할 수 있다.

공용 프로젝트의 부모 폴더는 프로젝트 소속 자료를 함께 포함하며 직접 소속 배열은 수정하지 않는다. 재검토 후보에서 게시 제외된 원본은 ID를 노출하지 않고 개수로 안내한다.

통합 검수 후 재검토 후보의 중복 자료 ID와 현재 게시 범위에 없는 변경 원본 ID 거부 테스트를 추가했다. 수정된 데이터 파서 테스트만 재실행하여 통과했다.

모바일 390px 실검수에서 연결 범위 버튼 잘림을 확인하여 3열 균등 너비와 선택 이동 별도 행으로 보정했다. 관계가 없는 범위는 자료를 유지하면서 관계 필터 안내를 제공한다. 재검수는 주 에이전트가 수행한다.

모바일 가장자리의 노드 라벨은 일반 상태에서 화면 안에 모두 들어가는 경우만 표시하고, 선택 라벨은 반대편 배치와 화면 내 위치 보정·길이 축소로 잘림을 줄였다. 관계 라벨도 화면 밖이면 숨긴다. 화면 좌표 배치 회귀 테스트를 추가했다.

모바일 공용 소속 필터를 포함한 마지막 필터 행과 지도가 겹치는 문제는 제목·필터·breadcrumb의 flex 축소를 방지하여 보정했다. 모바일 지도 하단 도움말은 숨기고 범례만 유지하며 키보드 안내는 canvas 접근성 설명에 보존했다.
